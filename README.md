Python Area Calculator

A simple Python program that calculates the area of different geometric shapes. This project was created to practice Python programming, mathematical formulas, and user input handling.

Features

The program supports the following geometric shapes:

1. Rectangle
2. Square
3. Triangle
4. Circle
5. Parallelogram
6. Trapezoid
7. Oval (Ellipse)
8. Right-Angle Triangle
9. Rhombus

* Interactive menu in the terminal
* User input for dimensions
* Area calculation using mathematical formulas
* Input validation for positive values
* Option to exit the program

Requirements

* Python 3.x

No external libraries are required if the program uses only Python’s built-in math module.

How to Run

1. Clone this repository:

git clone https://github.com/ChetsadaThammisarij/py-area-calculate.git

2. Navigate to the project folder:

cd py-area-calculate

3. Run the program:

python3 main.py

How to Use

1. Run the program in your terminal.
2. Choose a geometric shape from the menu.
3. Enter the required dimensions.
4. View the calculated area.
5. Choose another shape or enter 0 to exit.
